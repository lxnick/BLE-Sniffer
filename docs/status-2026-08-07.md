## 今天遇到的問題與處理

1. Sniffer dongle 大量吐出舊 buffer、follow 狀態停在 Idle，導致 capture timestamp
   異常且抓不到 ATT。實體重新插拔 dongle 後恢復。
2. Windows `pnputil /restart-device` 即使請求提升權限仍回報 Access denied；目前可靠
   的 reset 方法是實體重新插拔。
3. `--follow-by-name` 沒有辨識 scan response 名稱；改用固定 Peripheral random static
   address `CA:7B:30:B8:75:85`。
4. Secure Connections 使用臨時私鑰時，Sniffer 無法解密 ATT；兩端測試 firmware 改用
   Zephyr Bluetooth Core debug key，capture 時提供標準 DH private key。
5. `.venv` 原本指向已不存在的 Python 3.11；已用 bundled Python 3.12.13 原地重建。
6. `build_firmware.ps1` 在子 shell 找不到 nrfutil；已加入 WinGet packages recursive
   fallback。
7. 初版 `devices --all` 顯示無關 STM32 COM4；已限定只顯示 Nordic hardware 並加入
   regression test。
8. USB Hub/供電與重新枚舉曾不穩定；未來建議使用有獨立電源、可單埠開關的 Hub。
